## 👋 Sobre mí

Soy **Frontend Developer con más de 4 años de experiencia**, especializado en **Angular, TypeScript y RxJS**. He participado en el ciclo completo de desarrollo de aplicaciones web y móviles, desde la construcción de interfaces y componentes reutilizables hasta la integración con APIs REST, resolución de incidencias y mejora continua de productos.

Mi experiencia también incluye trabajo **Full-Stack** con **React, Ruby on Rails, NodeJS y MySQL**, además de un background en **Administración de Empresas** que me permite comprender tanto las necesidades técnicas como los objetivos del negocio.

- 🎯 Especialidad principal: **Angular + TypeScript + RxJS**
